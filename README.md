# 🌍 5초 분리수거 대작전 (1분 타임어택 교실 멀티플레이)

초·중학생들이 교실에서 모바일/태블릿으로 즐길 수 있는 **실시간 멀티플레이 분리수거 드래그 앤 드롭 1분 타임어택 퀴즈 게임**입니다.

---

## 🎮 주요 기능 및 업데이트 내용

1. **👨‍🏫 교사 전용 실시간 관전 & 진행 대시보드 (교사는 직접 플레이하지 않음)**:
   - 교사는 방을 개설하고 학생들을 입장시킨 후, **[게임 시작]** 버튼을 누릅니다.
   - 교사는 쓰레기 분리배출을 직접 하지 않으며, **교사용 실시간 관전 대시보드**로 전환됩니다.
   - 대형 스크린/빔프로젝터에 띄워둘 수 있도록 **1분 타이머 카운트다운**과 **학생들의 실시간 순위/점수 라이브 현황판**을 한눈에 볼 수 있습니다.
   - 필요 시 [🛑 지금 바로 게임 종료] 버튼으로 시상대로 즉시 이동할 수 있습니다.

2. **⏱️ 1분(60초) 타임어택 모드**:
   - 게임 시작과 동시에 전체 60초 타이머가 작동합니다.
   - 1분 동안 학생들은 5초 스피드 퀴즈를 연속해서 풀며 최대한 많은 점수를 획득합니다.
   - 60초가 지나면 게임이 자동으로 종료되며 영광의 시상대로 전체 이동합니다.

3. **👥 화면 상단 실시간 접속 학생 수 표시**:
   - 상단 헤더에 `👥 학생: X명` 뱃지가 항상 표시되어 몇 명의 학생이 참여하고 있는지 바로 확인 가능합니다.

4. **🏆 1분 종료 후 시상대(Podium) & 📊 1등부터 꼴등까지 전체 순위 결과보기**:
   - 1분 종료 시 1위(금), 2위(은), 3위(동) 단상 시상식이 팡파레 & 축하 폭죽과 함께 열립니다.
   - **[📊 1등부터 꼴등까지 전체 순위 결과보기]** 버튼을 누르면 참여한 모든 학생의 1등부터 꼴등까지의 순위, 닉네임, 최종 점수, 푼 문제 수, 환경 지킴이 등급이 모달 테이블로 깔끔하게 공개됩니다.
   - 선생님은 시상대에서 **[🔄 새 게임을 위해 대기실로 돌아가기]** 버튼을 눌러 전체 학생을 다음 게임을 위해 대기실로 일괄 복귀시킬 수 있습니다.

5. **단일 스프라이트 시트 완벽 분할 (Sprite Sheet)**:
   - 원본 이미지(`watermarked_img_2134683446226006262.png`) 단 1장을 CSS `background-image` & `background-position` 좌표로 정밀하게 잘라 모든 그래픽 에셋 렌더링:
     - 🗑️ **4종 분리수거함**: 플라스틱(파랑), 종이(노랑), 캔/고철(초록), 일반쓰레기(빨강)
     - 🧴 **20종 쓰레기 아이템**: 페트병, 구겨진 신문지, 참치캔, 바나나껍질, 영수증, 낡은 칫솔 등
     - 🐶 **마스코트 토이푸들 3종 표정**: 기본 미소(idle), 환호/정답(correct), 걱정/오답(wrong)
     - 🏆 **UI 에셋**: 1, 2, 3위 단상 시상대 및 축하 콘페티 파티클

## 🚀 실행 방법

### 방법 1. 원클릭 실행 (가장 추천)
* 폴더 안의 **`run_game.bat`** 파일을 더블 클릭하면 로컬 웹 서버가 실행되며 브라우저가 자동으로 열립니다! (`http://localhost:8080`)

### 방법 2. PowerShell로 직접 실행
```powershell
powershell -ExecutionPolicy Bypass -File .\start_server.ps1
```

### 방법 3. GitHub Pages 배포
* GitHub 저장소(`coolvine0918-bit.github.io` / `18-bit.github.io`)에 푸시하면 스마트폰/태블릿 브라우저로 어디서든 즉시 접속 가능합니다.
