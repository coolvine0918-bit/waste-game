# 🌍 3초 분리수거 대작전 (Drag & Drop Realtime Multiplay Game)

초·중학생들이 교실에서 모바일/태블릿으로 즐길 수 있는 **실시간 멀티플레이 분리수거 드래그 앤 드롭 스피드 퀴즈 게임**입니다.

---

## 🎮 게임 특징 및 주요 기능

1. **단일 스프라이트 시트 완벽 분할 (Sprite Sheet)**:
   - 원본 이미지(`watermarked_img_2134683446226006262.png`) 단 1장을 CSS `background-image` & `background-position` 좌표로 정밀하게 잘라 모든 그래픽 에셋 렌더링:
     - 🗑️ **4종 분리수거함**: 플라스틱(파랑), 종이(노랑), 캔/고철(초록), 일반쓰레기(빨강)
     - 🧴 **20종 쓰레기 아이템**: 페트병, 구겨진 신문지, 참치캔, 바나나껍질, 영수증, 낡은 칫솔 등
     - 🐶 **마스코트 토이푸들 3종 표정**: 기본 미소(idle), 환호/정답(correct), 걱정/오답(wrong)
     - 🏆 **UI 에셋**: 1, 2, 3위 단상 시상대 및 축하 콘페티 파티클

2. **초스피드 3초 타이머 & 즉각 반응형 UI**:
   - 3초 제한시간 게이지 바가 줄어들며 1초 미만 시 긴박한 빨간색 깜빡임 경고.
   - 3초 내 정답 수거함에 드래그 성공 시: **+10점**, 초록 글로우 효과, 토이푸들 환호 표정 전환 및 딩동댕 사운드.
   - 오답 수거함 또는 3초 타임아웃 시: **-5점**, 화면 진동(Shake) 효과, 토이푸들 오답 표정 전환 및 말풍선 피드백 힌트 출력.
   - 지연 시간 없이 즉시 다음 쓰레기가 팝업되어 긴장감 유지.

3. **실시간 멀티플레이 & 리더보드 (Firebase Realtime Database & 가상 멀티플레이)**:
   - **가상 멀티플레이 엔진(기본 내장)**: 별도의 Firebase 설정 없이도 같은 브라우저의 여러 탭이나 창에서 동시에 접속하여 실시간 동기화 플레이 가능 (`BroadcastChannel` & `localStorage`).
   - **정식 Firebase Realtime Database 연동**: 우측 상단 ⚙️ 설정 버튼을 눌러 Firebase Database URL과 키를 입력하면 교실 내 수십 대의 모바일/태블릿에서 실시간 접속 및 동시 화면 전환 가능.

4. **터치 & 포인터 이벤트 최적화**:
   - 데스크톱 마우스 및 모바일/태블릿 터치 화면 모두에서 부드럽게 드래그 앤 드롭 (`Pointer Events`, `touch-action: none`).

5. **20라운드 완주 후 시상대(Podium) & 축하 파티클**:
   - 20라운드 종료 후 전원 자동으로 시상대 화면으로 이동.
   - 1위, 2위, 3위 단상 위에 학생 닉네임과 점수 발표 및 왕관 👑 애니메이션.
   - 화면 전체에 팡파레 사운드와 함께 폭죽 콘페티 파티클 분출.

## 🚀 실행 방법

### 방법 1. 원클릭 실행 (가장 추천)
* 폴더 안의 **`run_game.bat`** 파일을 더블 클릭하면 로컬 웹 서버가 실행되며 브라우저가 자동으로 열립니다! (`http://localhost:8080`)

### 방법 2. PowerShell로 직접 실행
```powershell
powershell -ExecutionPolicy Bypass -File .\start_server.ps1
```

### 방법 3. 브라우저에서 직접 열기
* 크롬/엣지/웨일 브라우저에서 `index.html` 파일을 더블 클릭하여 실행합니다.

---

## 📂 파일 구조

* `index.html`: 대기실(Lobby), 본 게임(In-Game), 시상대(Podium) 통합 마크업
* `style.css`: 모바일/태블릿 반응형 디자인, 글래스모피즘, 3초 타이머 애니메이션, 화면 흔들림 효과
* `sprite.js`: 단일 스프라이트 이미지 좌표 정의 및 CSS background-position 계산 모듈
* `sound.js`: Web Audio API 기반 무지연 내장 신디사이저 사운드 시스템
* `firebase-sync.js`: Firebase Realtime Database 및 가상 멀티플레이 동기화 엔진
* `game.js`: 드래그 앤 드롭, 판정 로직, 점수 계산, 마스코트 표정 제어 메인 컨트롤러
* `watermarked_img_2134683446226006262.png`: 4종 수거함, 20종 쓰레기, 마스코트 3종, 시상대가 통합된 원본 스프라이트 시트
